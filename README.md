# Simple Gemini Chat

<img width="1365" height="647" alt="image" src="https://github.com/user-attachments/assets/4d97e60f-0a64-4e26-8057-b9762a4be9e9" />


Small fullstack app with a minimal React UI, voice input, and a Node.js backend that calls Gemini API.

## How to run

```bash
npm start
```

Then open:

```text
http://localhost:3000
```

The Gemini API key is read from `.env` on the backend and is not sent to the browser.
